## Kaprekar's Routine

[Kaprekar's Routine](https://en.wikipedia.org/wiki/Kaprekar%27s_routine) is a math algorithm created by Kaprekar. It goes like this:

0. Choose any 4 digit number with at least 2 different digits
1. Create the largest possible number with the digits from the number by ordering it's digits from biggest to smallest
2. Create the smallest possible number with the digits from the number by ordering it's digits from smallest to biggest
3. Substract the smaller number from the bigger number
4. Repeat from step 1 with the newly obtained number

## This project

This project is all about explaining and showing the beauty of this algorithm using animations and simple explanations
